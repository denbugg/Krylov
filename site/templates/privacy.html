Политика конфиденциальности

Сайт ELITE использует контактные данные, которые посетитель добровольно передаёт через форму, только для связи по заявке на занятия.

Какие данные собираются

Телефон обязателен для обратного звонка; имя можно указать по желанию. Технически могут сохраняться источник заявки, страница и UTM-метки для оценки рекламы.

Для чего

Чтобы связаться с родителем, уточнить подходящую группу, время и формат первого занятия.

Хранение

Заявки хранятся в защищённой базе данных на сервере сайта и не публикуются в Git-репозитории. Доступ ограничивается техническими и административными средствами.
